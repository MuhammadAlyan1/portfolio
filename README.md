# alyan.dev — Portfolio

Personal portfolio of [Alyan Hanif](https://alyan.dev), AI Full Stack Engineer. Built with Next.js 14 (App Router), TypeScript, and Tailwind CSS. Statically generated and deployed on Vercel.

## Getting started

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build
npm run start    # serve the production build
```
